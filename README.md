🖥️ TechZone | Tienda de Tecnología

TechZone es un sitio web de comercio electrónico ficticio, desarrollado como proyecto académico para aplicar conocimientos de HTML5, CSS3 y JavaScript.

El proyecto presenta una tienda especializada en accesorios y dispositivos tecnológicos, con una interfaz moderna, minimalista y adaptable a diferentes tamaños de pantalla.

Su diseño sigue el concepto Minimal Tech, utilizando una paleta monocromática, componentes reutilizables y una navegación sencilla.

📌 Descripción del proyecto

TechZone permite a los visitantes explorar una selección de productos tecnológicos, filtrarlos por categorías, consultar sus características y acceder a un formulario de contacto.

El proyecto está desarrollado principalmente con tecnologías frontend, sin frameworks, con el objetivo de fortalecer los fundamentos del desarrollo web.

📱 Diseño responsive

TechZone está diseñado para adaptarse a diferentes resoluciones mediante Media Queries de CSS3.

Se trabajaron principalmente los siguientes puntos de adaptación:

Resolución

Adaptación

Escritorio

Diseño completo con múltiples columnas

Hasta 1200 px

Ajustes de distribución y espaciado

Hasta 768 px

Reorganización de elementos para tablets y móviles

Hasta 378 px

Optimización para pantallas estrechas

Se utilizan CSS Grid y Flexbox para reorganizar los componentes sin alterar la identidad visual del sitio.

🚀 Instalación y ejecución

Para ejecutar TechZone localmente:

1. Clonar el repositorio

git clone https://github.com/USUARIO/TechZone.git

Reemplaza USUARIO por el nombre de la cuenta de GitHub correspondiente.

2. Abrir la carpeta

cd TechZone

3. Ejecutar el proyecto

Abre index.html en tu navegador.

También puedes utilizar la extensión Live Server de Visual Studio Code para visualizar los cambios durante el desarrollo.

No se requiere instalar Node.js ni ejecutar un servidor backend para explorar las funcionalidades frontend del proyecto.

Algunos íconos utilizan Lucide desde una CDN, por lo que requieren conexión a Internet para visualizarse correctamente.

🔎 Aspectos técnicos

Frontend: HTML5, CSS3 y JavaScript.

Backend: no implementado.

Tipo de sitio: sitio web multipágina con contenido principalmente estático y funcionalidades dinámicas ejecutadas en el navegador.

Accesibilidad: se incorporan elementos semánticos, textos alternativos para imágenes, etiquetas de formulario y atributos ARIA en componentes interactivos.

SEO básico: se utilizan títulos de página, encabezados jerárquicos y estructura semántica.

⚠️ Alcance del proyecto

TechZone es una demostración académica y no constituye una tienda comercial operativa.

Los productos, precios y especificaciones se presentan con fines ilustrativos. No se procesan compras, pagos ni pedidos reales.

Las interacciones con filtros y modales funcionan desde el navegador. El formulario de contacto valida los datos ingresados, pero no transmite mensajes a un servidor.
